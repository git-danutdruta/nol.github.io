# Privacy Policy (Draft)

Last updated: 2026-08-04

## Status

This policy is a project draft for an open-source educational app and is not legal advice. Seek legal review before public launch.

## Who we are

NOL Math is a static, browser-based math learning application distributed as open-source software.

## Data we process

### Data stored locally on your device

The app stores learning progress in your browser storage, such as:

- lesson completion and attempt history,
- XP/badges and review schedule,
- optional drawing and diagnostics data,
- onboarding/settings preferences.

This data is stored locally in your browser and is not sent to a server by default.

### Data you choose to export

If you use export features, the app generates a local file on your device. You control where it is stored and whether you share it.

### Data we do not collect by default

- No account registration data.
- No email addresses.
- No payment information.
- No backend analytics pipeline by default.

## Cookies and tracking

The app does not require third-party tracking cookies for core functionality.

If optional analytics are enabled in a future release, this policy must be updated and any required consent controls will be provided.

## Security note

Local browser storage can be cleared by browser actions, profile resets, or device changes. Users should export backups regularly if progress matters.

## Children and education context

The app is intended for learners, including minors, under educator/guardian discretion. Because data is local-only by default, personal profile collection is minimized.

## Open-source hosting

When hosted on static platforms (for example GitHub Pages), platform operators may process standard web logs under their own policies. Refer to host provider terms for details.

## Your choices

- Export your progress at any time.
- Import previously exported progress.
- Reset local progress from settings.
- Clear local browser data using browser controls.

## Contact

Project maintainers can be reached through the repository issue tracker for policy questions or correction requests.

## Changes to this policy

Policy updates are versioned in git. The "Last updated" date will change when material changes are made.

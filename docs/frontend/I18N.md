# Internationalization (i18n)

NOL Math uses `i18next` with `react-i18next` for UI string localization.

## Supported Languages

- English (`en`)
- French (`fr`)
- Romanian (`ro`)

## How to Add a Language

1. Create a new folder under `web/public/locales/<lang>/`.
2. Add a `translation.json` file with the same keys as the English file.
3. Open `web/src/i18n/config.ts` and add the language code to `supportedLngs`.
4. Restart the dev server so Vite serves the new locale files.

## Best Practices

- Keep UI strings in translation files; do not hardcode text in components.
- Use namespaces if the app grows (e.g., `translation`, `curriculum`, `errors`).
- Use `t('key', { count })` for pluralization when needed.
- Locale-aware number and date formatting should use `Intl.NumberFormat` and `Intl.DateTimeFormat` via helpers in `src/lib/utils.ts`.
- Math symbols (e.g., `+`, `=`, `π`) should remain consistent across locales; only natural-language text is translated.

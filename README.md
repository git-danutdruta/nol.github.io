# nol.github.io

Learning math from top to bottom.

A free, open-source, offline-capable math learning PWA deployed to GitHub Pages.

## Project Structure

- `web/` — React + TypeScript + Vite frontend.
- `docs/` — Product, frontend, and legal documentation.
- `.github/workflows/` — CI/CD for build, test, and deploy.

## Quick Start

```bash
cd web
pnpm install
pnpm dev
```
